# Архитектура ПРОЧАЙ

## Веб-демо

- HTML-шаблоны и CSS в `design/` описывают экраны. Согласованные решения по оформлению и поведению собраны в [дизайн-доке](../design/spec.md).
- Модуль каталога читает статический JSON, связывает товары с фасовками и локальными фотографиями. Экраны используют этот модуль для доступа к данным.
- У каждой фасовки есть числовой размер и единица из типа `Unit`. Каталог проверяет их при чтении JSON. Экраны используют вид единицы (вес, объём или количество) и общий форматтер русских подписей.
- Корзина хранит количество по идентификатору фасовки, избранное — идентификаторы товаров. Оба списка живут в памяти открытой страницы. Навигация запоминает раздел, запрос и позицию прокрутки при возврате по истории браузера.
- TypeScript отвечает за действия и переходы. Проект использует Node.js и npm. Vite собирает статический сайт для локального ревью PR. После успешных проверок коммита в `main` GitHub Actions публикует его сборку на GitHub Pages. [Сборка и публикация](../design/publish/README.md)

## Мобильное приложение

- Для будущего клиента согласованы Expo, React Native, TypeScript, Expo Router и нативный Stack с мгновенной сменой экранов. Для оформления — `StyleSheet` и общая тема.
- Веб-демо служит эталоном. Для iOS и Android планируется общая нативная реализация экранов. Данные каталога, фотографии и правила корзины можно использовать повторно.
- Мобильные экраны получают модели товаров через асинхронный контракт каталога. Источник выбирается в одном месте. Для подключения сайта или API достаточно адаптера с тем же контрактом.
- Экран связывает данные с действиями. Визуальные компоненты получают модель и обработчики через параметры. Корзина и избранное общие для экранов через Context и `useReducer`. При новом запуске оба списка пусты.
