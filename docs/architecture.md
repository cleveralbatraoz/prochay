# Архитектура мобильного приложения ПРОЧАЙ

- **Клиент.** Expo, React Native и TypeScript. Общие экраны для обеих платформ, навигация через Expo Router и нативный Stack. Для оформления — `StyleSheet` и общая тема. Короткий чайный акцент на переходе — встроенный `Animated`. Действия доступны во время анимации.
- **Данные.** Вручную подготовленный каталог и фотографии входят в сборку и работают офлайн. Экраны получают модели товаров через асинхронный контракт каталога. Источник выбирается в одном месте. Для подключения сайта или API достаточно адаптера с тем же контрактом.
- **Компоненты.** Экран связывает данные с действиями. Визуальные компоненты получают модель и обработчики через параметры. Прямой импорт файла каталога допустим только в адаптере.
- **Состояние.** Корзина и избранное общие для экранов и живут в памяти через Context и `useReducer`. Избранное хранит ID товара, корзина — ID фасовки и количество. При новом запуске оба списка пусты.
- **Проверка.** Компонентные тесты используют React Native Testing Library и тестовые данные. Проверяем путь из каталога в корзину, возврат к прежней позиции и плавность переходов на iOS и Android.
- **Стек разработки.** TypeScript и TSX, Node.js для скриптов и сборки, npm для зависимостей. Vite собирает веб-плеер из исходников Doop закреплённой ревизии.
- **Публикация демо.** На рабочем компьютере экспорт из Doop готовит статические файлы. `rclone sync` по SFTP обновляет одну папку на VPS и удаляет устаревшие файлы. Caddy раздаёт содержимое этой папки по HTTP.
