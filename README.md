# ПРОЧАЙ

Мобильное приложение для чайного магазина «ПРОЧАЙ». Сейчас доступен интерактивный веб-прототип с каталогом, избранным и корзиной.

[Открыть демо](https://cleveralbatraoz.github.io/prochay/)

Прототип собран на HTML, CSS и TypeScript с помощью Vite. Для приложения на iOS и Android выбраны Expo, React Native и TypeScript.
