# Дизайн мобильного приложения ПРОЧАЙ

Монорепозиторий мобильного приложения ПРОЧАЙ для iOS и Android.

Ориентиры по дизайну — приложения Дринкит и Додо Пицца. Чайная анимация служит коротким акцентом при переходе между экранами. Действия на экране доступны во время анимации.

## Каталог

Стартовый экран — каталог. [Публичное демо](http://157.22.181.155/) открывает версию из `main` в браузере телефона. Рабочий макет доступен на [холсте Doop](http://127.0.0.1:4400/c/fhOB6DlNAZ) и в [локальном плеере](http://127.0.0.1:4400/c/fhOB6DlNAZ/proto?frame=UA_-7Clvlp).

- 70 товаров в трёх разделах. В «Чае» 52 позиции, включая каркаде и дегустационный набор, в «Посуде» 12, в «Аксессуарах» 6. В разделе «Все» первым показан шу пуэр «Зелёные холмы Юньнани», далее идут товары из разных разделов. Переключатель разделов остаётся доступным при прокрутке.
- Карточки каталога показывают фотографию, вид товара, название и цену за указанную единицу. В карточке товара можно прочитать описание, сохранить товар или положить его в корзину. Для «Зелёных холмов Юньнани» доступны две фасовки. [100 г в разломе](https://www.prochay.ru/catalog/katalog-chaya/proizvodstvo-prochay/2135/) · [Кирпич 500 г](https://www.prochay.ru/catalog/katalog-chaya/proizvodstvo-prochay/2132/)
- В шапке рядом с фирменной чашкой написано «ПРОЧАЙ». Заголовки набраны Georgia. Внизу три вкладки — «Каталог», «Избранное» и «Корзина». В карточках «Зелёные холмы Юньнани», «Моли Хуа Люй Ча» и «Каркаде» чайный лист проявляется за 180 мс. При включённом уменьшении движения он виден сразу.
- Плеер показывает подготовленные состояния. Для каждого товара доступны избранное и корзина с одной или двумя единицами. Для «Зелёных холмов Юньнани» можно сочетать обе фасовки. В карточках с кнопкой «Назад» она возвращает к началу того раздела каталога, из которого открыт товар. Переход через вкладку «Каталог» начинает новый сценарий.

[Каталог товаров](doop/catalog/products.json) хранит названия, категории, цены, единицы продажи и ссылки на фотографии и карточки ПРОЧАЙ. Данные зафиксированы для демо. [Исходные JPEG магазина](assets/catalog/) хранятся в Git LFS. Имена файлов соответствуют идентификаторам 70 товаров. Карточки обеих фасовок пуэра используют [дополнительный снимок](assets/catalog/tea-detail.jpg). При обновлении каталога загружаем эти файлы на локальный сервер Doop в исходном разрешении, без повторного сжатия. Публичный плеер загружает эти фотографии с того же сервера, что и экраны.

[Шаблоны каталога](doop/catalog/) и [разметка списка](doop/catalog.html) задают представление товаров. Команда `node design/doop/catalog/render.ts .local/catalog/rendered` собирает HTML для Doop из данных. [Манифест](doop/prototype.json) связывает имена состояний с фреймами холста. Для экранов с отдельными HTML-файлами цели переходов хранятся в `frames[].sourceFrameId`, для экранов из шаблонов — в `generated.frames`.

## Палитра

- Фон — кремовая бумага `#F5EFDF`, текст и кнопка покупки — тёмная тушь `#222B24`. Подписи — серо-оливковые `#625F52`.
- Подложка пуэра в каталоге переходит от светлого янтаря `#E5B474` к насыщенному `#CE7E35`. Цена главного чая и отметка выбранной фасовки — глиняные `#963F2C`.
- Выбранная фасовка и активная вкладка выделены светло-медовым `#F9DEAA`. [Цветовые токены](doop/tokens.json)
